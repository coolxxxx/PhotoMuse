# 光影集 PhotoMuse · 上线检查清单

> 代码库已通过四层自动化验证（`npm test`：文案/结构断言 + 契约交叉核对 + 视觉完整性 + 46 个集成用例）与页面 JS 运行时冒烟。
> 以下是**本地无法验证、必须真机/云端操作**的清单，按顺序执行。

## 一、云开发部署（约 30 分钟）

1. **上传全部云函数**（30 个，微信开发者工具右键逐个"上传并部署：云端安装依赖"，或 CloudBase CLI 按 `cloudbaserc.json` 批量部署）
   - ⚠️ `generateAIStudioImage` 部署后**手动把超时改为 120 秒**
   - ⚠️ `exportAIStudioPrintFile` 首次部署会在线装 jpeg-js/pngjs，内存 512MB
   - ⚠️ `analyzeAIStudioPhoto` 超时改 40 秒
2. **建 4 个新集合**（不建也能跑，有代码内置默认值，但后台改配置需要）：
   `ai_studio_business_config` / `ai_studio_samples` / `ai_studio_merchandise` / `ai_studio_payment_config`
3. **配置环境变量**（云函数控制台，配置模板见 cloudbaserc.json）：
   - 管理员函数（admin* 系列 + dispatch/generate/export 等）：`AI_STUDIO_ADMIN_OPENIDS`（你的 OPENID）、`AI_STUDIO_ADMIN_PASSWORD`（⚠️ 现在是空串=管理接口全封死，必须填）
   - `photomuseOpenApi`：`AI_STUDIO_OPEN_API_KEYS`（openssl rand -hex 16 生成）
4. **数据库权限**：7 个 ai_studio_* 业务集合建议"仅创建者可读写"，配置类集合（business_config/samples/merchandise/payment_config）可"所有人可读"（敏感字段读取接口已剥离）

## 二、小程序真机回归（微信开发者工具打开 F:\PhotoMuse）

按此路径走一遍（集成测试已验证云函数逻辑，这里验的是真机 UI/上传/预览）：
1. 下单：选证件照 → 传图 3 张 → 授权 → 提交 → 详情；换写真套餐 → 多选主题看价格条 → AI 帮我选主题（需先配视觉模型，见下）→ 场景描述 → 提交
2. 我的订单/三元组查询 → 详情
3. 管理登录 → 各状态 tab → 通过/重拍/上传网格/标记已付/开始制作/发货/导出制作稿
4. 四个设置面板：收款设置（传收款码）/模型设置/样张管理/定价设置
5. showcase 场景模拟：六场景切换、换片、提交周边
6. 重点观察：衬线字体真机效果（中文退宋体是否可接受）、拍立得样张区、步骤条

## 三、AI 接口配置（管理后台-模型设置）

- **生图**（scene: image_generation）：OpenAI 兼容完整地址，如智谱 `https://open.bigmodel.cn/api/paas/v4/images/generations` + Key + 模型名（cogview-4）
- **视觉分析**（scene: photo_analysis）：`https://open.bigmodel.cn/api/paas/v4/chat/completions` + Key + glm-4v 类模型——配好才有"AI 帮我选主题"
- 配完先在管理端对测试订单点"生成参考图"跑通全链路

## 四、网站版（photomuse-web/）

1. 改 `js/config.js`：ENV_ID + OPEN_API_KEY（与上面第 3 步同一把 key）
2. 上传到服务器，nginx 配置见 `photomuse-web/nginx.conf`（注意 client_max_body_size 12m）
3. CloudBase 控制台：**安全域名**加入你的域名；**启用匿名登录**（身份验证方式）
4. 云存储权限放行 ai-studio/ 前缀匿名读写（收紧版规则见 Web 版部署指南）
5. 浏览器实测：下单 → 传图（Web SDK 直传）→ order 页 → 查询页 → showcase

## 五、已知边界（非缺陷，按需排期）

- 上传为串行（每单最多 3 张，慢 2-3 秒，可后续并行化）
- 印刷稿为 sRGB 300DPI + 出血 + 制作单（含打样提示）；真 CMYK 需 ICC 引擎，列 Roadmap
- Web 端 API Key 前端可见：建议独立低权限 key + 定期轮换 + 审计监控
- 微信支付未接（现为人肉收款码确认模式）
