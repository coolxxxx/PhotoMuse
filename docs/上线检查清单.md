## 三、网站版（photomuse-web/ + photomuse-server/）

> **废弃说明**：`photomuse-web/js/config.js`、`js/tcb-transport.js`、`js/vendor/cloudbase.full.js` 已废弃且无引用，可删除（本次不动它们）。

1. 上传静态目录 `photomuse-web/` 到服务器（前端无需改配置；页面经 `js/api.js` 请求同源 `/PM/api`）
2. 部署独立后端 `photomuse-server/`：端口与环境变量见 `photomuse-server/server.js` 顶部（`PORT` 默认 8900、`PM_ADMIN_PASSWORD` 必填、`PM_UPLOAD_ROOT` 上传目录、`PM_PUBLIC_ORIGIN`）
3. nginx：静态托管见 `photomuse-web/nginx.conf`（注意 client_max_body_size 12m）；TODO：`/PM/api/` 反代到 `127.0.0.1:8900`、`/PM/uploads/` 静态指向 `PM_UPLOAD_ROOT`，具体写法需按实际环境确认
4. 管理后台 `admin.html`：口令登录（`PM_ADMIN_PASSWORD`）→ 请求头 `X-Admin-Token` 调 `/PM/api/admin/*`
5. 浏览器实测：下单 → 传图（`/api/upload` 落盘 uploads/）→ order 页 → 查询页 → showcase
