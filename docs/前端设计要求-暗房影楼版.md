## 一、设计问题诊断（为什么 v2 "没有影楼感"）

v2 走的是"杂志纸面"路线：暖白底 + 品牌蓝 + 发丝线。它干净，但本质是**文档的质感**，不是**影楼的质感**。三个核心问题：

1. **底色错了**：影楼的作品诞生在暗房/影棚里。白底页面里放照片，照片像"贴在墙上的证件照"；暗底页面里放照片，照片才像"灯下的成片"——暗场让照片成为发光的主体。
2. **颜色语言错了**：品牌蓝是"科技/工具"的语言。影楼的高端感来自**香槟金/古铜**（参考妈妈套礼服的香槟色、影楼相册的烫金），它传递"仪式感与珍藏"。
3. **照片没有地位**：首页 hero 是纯文字，我们最好的资产（影楼级样张）完全没有出现在门面上。影楼网站的第一原则：**让客户看到成片**。

## 二、设计理念：三句话

1. **页面即暗房，成片即发光体**——大面积极简的深暖炭黑底，让每一张照片、每一块白色卡片像灯下浮起。
2. **浅焦美学**——"浅焦映像"的品牌名就是设计语言：主体锐利（金色点缀、衬线大字、清晰层级），背景虚化（大面积低对比暗部、微渐晕）。
3. **相纸质感**——所有承装内容的容器都是"相纸"：纯白卡片浮在暗场上、样张用拍立得白边、投影要"浮起"而不是"贴着"。

## 三、色板令牌（双端对照）

### 暗场基底

| 令牌 | 值 | 用途 | 网站 CSS 变量 | 小程序建议 |
|---|---|---|---|---|
| 暗房底 | `#15161A` | 页面背景 | `--dr-bg` | `$dr-bg` |
| 暗房抬升层 | `#1C1E24` | 次级区块底 | `--dr-bg-2` | `$dr-bg-2` |
| 暗角/渐变 | `radial-gradient(120% 90% at 50% 0%, #1E2026, #15161A 55%, #101114)` | body 背景（fixed） | 见 style.css v3 层 | 页面根节点背景 |

### 香槟金系（唯一 accent，替代品牌蓝）

| 令牌 | 值 | 用途 |
|---|---|---|
| 香槟金 | `#C8A86B` | 主 accent：编号、图标、active 态、细线 |
| 亮金 | `#E3C892` | 标题/hover/强调文字 |
| 金·弱 | `rgba(200,168,107,0.35)` | 分隔线、辅助说明 |
| 金·底 | `rgba(200,168,107,0.14)` | 标签底、选中态底 |

### 文字与相纸

| 令牌 | 值 | 用途 |
|---|---|---|
| 暖白 | `#F5F2EC` | 暗底上的主文字 |
| 暖灰 | `#B9B4A9` | 暗底上的次级文字 |
| 相纸白 | `#FFFFFF` | 内容卡片底（承装表单/文字的白卡） |
| 拍立得白 | `#F7F4EE` | 样张白边、照片卡 |
| 墨色 | `#1B1F24`（沿用 v2） | 白卡上的正文 |

### 线与投影

| 令牌 | 值 | 用途 |
|---|---|---|
| 暗场发丝线 | `rgba(255,255,255,0.09)` | 暗区分隔 |
| 金发丝线 | `rgba(200,168,107,0.4)` | 顶栏/页脚边、重点分隔 |
| 相纸投影 | `0 18px 44px rgba(0,0,0,0.5)` | 白卡片浮起感 |
| 拍立得投影 | `0 14px 34px rgba(0,0,0,0.55)` | 样张照片 |

### 保留的语义色

成功/警示/错误沿用 v2 低饱和值（`#2E6B3F / #C66A2E / #B23A3A`），只出现在白卡内部，不进入暗区。

## 四、字体与排版

1. **衬线继续当主角**（与 v2 一致）：`Georgia, 'Songti SC', SimSun, serif`。暗底上衬线大字 + 金色细线 = 仪式感。
2. Hero 大字：`浅焦·映像`，字号 ≥ 44px（web）/ 72rpx（小程序），字后跟 56px 金色渐变短横线（快门线意象）。
3. 眉题（eyebrow）：`SHALLOW FOCUS STUDIO — No.01`，10-11px，letter-spacing ≥ 0.3em，香槟金色。中英混排的"呼吸感"靠超大字距。
4. 正文 14px / 行高 1.65 不变；暗底上正文一律暖白/暖灰，**禁止纯白 `#FFF` 直接做正文**（刺眼）。

## 五、组件规范

### 1. 顶栏 / 导航
- 暗底（92% 透明 + 6px 毛玻璃）、底边金色发丝线
- 链接：暖灰；当前页：亮金

### 2. Hero（首屏，全站统一）
- 结构：眉题（金）→ 大衬线标题（暖白，带金色微光晕 text-shadow）→ 金色短横线 → 副标题（暖灰）→ **样张拍立得叠放**
- 样张叠放：3 张照片，白边（7px，底边 26px 留白做"相纸"），各旋转 -7°/+2°/+8°，居中交叠，hover 浮起转正；下方配 10px 金色弱字 `成片样张 · SHALLOW FOCUS`
- 图片必须用**已交付的真实成片样张**（服务器 `/PM/img/` 下三张），禁止用占位图/示意图
- 高度预算：桌面 ~300px，小屏 ~240px

### 3. 内容卡片（表单/信息容器）
- 纯白底 + 相纸投影 + 6px 圆角，浮于暗场
- 卡片内部完全沿用 v2 排版（墨色文字、发丝线、№ 编号）
- ** № 工序编号升级为金色衬线**——白卡上的金编号是"相册烫金"的语言

### 4. 主按钮（快门键）
- 金色渐变底（`135deg, #E3C892 → #C8A86B`）+ 黑棕字（`#17130A`）+ letter-spacing 0.14em
- 投影带金色：`0 6px 22px rgba(200,168,107,0.28)`
- 禁用态：降饱和至 40%，禁用蓝灰

### 5. 样张卡（下单页主题样张条）
- 拍立得语言：`#F7F4EE` 白边、下宽边、轻旋转可选、深投影
- caption 沿用现有衬线小字

### 6. 状态徽章 / 标签
- 选中/强调：金底（14% 透明度）+ 亮金字 + 金描边
- 成功/警示/错误：白卡内沿用 v2 语义色

### 7. 表单控件
- 输入框保持白底（在暗场上自然成为焦点），focus 态：金色下划线（替代 v2 蓝色）

## 七、红线（Do NOT）

1. ❌ 禁止在页面中出现**任何摄影器材图案**（相机、柔光箱图标等）——品牌语言里只谈"成片"，不谈"器材"（与生图 prompt 同一原则）
2. ❌ 禁止纯黑 `#000` 做底色（死黑没有暗房感，必须用带暖调的 `#15161A` 系）
3. ❌ 禁止蓝金混用——金色是这个版本的唯一 accent，v2 的品牌蓝从主视觉中全面退场（错误/成功语义色除外）
4. ❌ 禁止高饱和渐变横幅、彩虹配色、大面积金色铺底（金是点缀，占比 < 10%）
5. ❌ 暗底上的正文禁止纯白 `#FFF` 与细字体（细字重 + 深底 = 发虚）
6. ❌ 照片一律用真实成片样张，禁止插画/占位图
7. ❌ 不改任何 JS 交互逻辑与数据绑定（本次是表现层升级，接口契约零变动）

## 八、验收清单

- [ ] 首屏能在 3 秒内让人说出"这是影楼/摄影品牌"（暗场 + 金 + 大片样张三要素齐）
- [ ] 页面上至少出现 3 张真实成片样张
- [ ] 白色卡片在暗场上有明显"浮起"投影
- [ ] 全页只有一个 accent 色（香槟金），无蓝金混杂
- [ ] 暗底文字对比度 ≥ 4.5:1（暖白 #F5F2EC / 暖灰 #B9B4A9 达标）
- [ ] 手机端（375px）与桌面（1280px）双端布局不破
- [ ] 小程序 `npm test` 全绿（冻结断言零破坏——本次只动表现层，wxml 断言子串如「上传正脸照」「‹」「提交证件照订单」「example-image」必须原样保留）
