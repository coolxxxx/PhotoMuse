# 浅焦映像（PhotoMuse）· 开放接口接入指南

本文面向希望接入浅焦映像 AI 影楼能力的**网站开发者、其他小程序开发者、第三方后端开发者**，说明如何获取套餐目录、查询订单、获取收款码与运行配置。

一期仅开放**只读 + 查询**能力；下单类接口涉及微信 OPENID 归属，暂不对外开放，仍请引导用户到浅焦映像小程序内完成下单与支付。

---

## 一、三种接入方式对比

| # | 接入方式 | 适用场景 | 鉴权方式 | 可调用能力 | 用户身份（OPENID）归属 |
|---|---------|---------|---------|-----------|----------------------|
| ① | **其他小程序** | 微信小程序之间合作导流 | 云开发「环境共享 / 资源授权」，被授权方直接 `wx.cloud.callFunction` 调用 | 浅焦映像的 13 个业务云函数（下单、查询、上传、客服等） | 自动归属：微信自动注入调用方用户的 OPENID，`_openid` 天然隔离 |
| ② | **网站（Web）** | 官网、H5、第三方网站 | CloudBase Web SDK（`@cloudbase/js-sdk`）匿名登录后 `callFunction` | 同样直调 13 个业务云函数 | 匿名登录身份（无微信 OPENID） |
| ③ | **任意后端 / HTTP** | 自有服务器、脚本、第三方系统 | 为 `photomuseOpenApi` 云函数开启云接入（HTTP 访问服务），请求信封携带 **API Key** | 仅 `photomuseOpenApi` 的 4 个只读 action：`catalog` / `queryOrder` / `paymentQR` / `runtimeConfig` | 无 OPENID，以 API Key 识别接入方来源，全部调用写入审计日志 |

**13 个业务云函数清单**（方式 ①② 可直调）：

| 分类 | 函数名 |
|------|--------|
| 订单与交付 | `createAIStudioOrder`、`submitAIStudioOrder`、`listMyAIStudioOrders`、`getAIStudioOrderDetail`、`queryAIStudioOrder`、`uploadAIStudioPhoto` |
| 客服与调度 | `callAIStudioCustomerService`、`dispatchAIStudioJob` |
| 配置 | `getAIStudioRuntimeConfig` |
| 管理（内部使用，第三方请勿调用） | `adminListAIStudioOrders`、`adminReviewAIStudioOrder`、`adminDeliverAIStudioOrder`、`adminUpsertAIStudioRuntimeConfig` |

### 方式 ①：其他小程序（环境共享）

先在浅焦映像所属环境的控制台完成「环境共享 → 资源授权」，授权对方 AppID 后，对方小程序中这样调用：

```js
// 被授权方小程序代码
const photomuse = new wx.cloud.Cloud({
  resourceAppid: '浅焦映像小程序 AppID',
  resourceEnv: '浅焦映像云开发环境 ID'
});
await photomuse.callFunction({
  name: 'queryAIStudioOrder',
  data: { orderId: '...', contactPhone: '...', queryPassword: '...' }
});
```

### 方式 ②：网站（CloudBase Web SDK）

```js
import cloudbase from '@cloudbase/js-sdk';

const app = cloudbase.init({ env: '浅焦映像云开发环境 ID' });
const auth = app.auth({ persistence: 'local' });
await auth.signInAnonymously(); // 匿名登录后即可 callFunction

const res = await app.callFunction({
  name: 'queryAIStudioOrder',
  data: { orderId: '...', contactPhone: '...', queryPassword: '...' }
});
console.log(res.result);
```

### 方式 ③：任意后端 / HTTP

为 `photomuseOpenApi` 开启云接入（HTTP 访问服务，建议路径 `/openapi`）后，向该地址 `POST` JSON 信封即可，详见下文契约。

## 二、photomuseOpenApi 接口契约（HTTP / 跨端统一网关）

### 2.1 统一请求信封

所有请求均为 `POST`，`Content-Type: application/json`，请求体为单一信封：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `apiKey` | string | 是 | 接入凭证。trim 后必须等于环境变量 `AI_STUDIO_OPEN_API_KEYS`（逗号分隔多 key 白名单）之一，否则返回 `FORBIDDEN` |
| `action` | string | 是 | 取值：`catalog` / `queryOrder` / `paymentQR` / `runtimeConfig` / `businessConfig` / `samples` / `merchandise` / `createOrder` / `registerPhoto` / `submitOrder` / `getOrder` / `selectCells` / `analyzePhoto` / `selectMerch` |
| `payload` | object | 否 | 业务参数，默认 `{}` |

### 2.2 统一错误码

失败时统一返回 `{ success: false, code, message }`：

| code | message | 触发条件 |
|------|---------|---------|
| `FORBIDDEN` | 无效的 API Key | apiKey 缺失或不在白名单 |
| `VALIDATION_ERROR` | 不支持的 action | action 缺失或不是 4 个之一 |
| `VALIDATION_ERROR` | 请填写订单号、手机号和查询密码 | queryOrder 三元组不完整或密码不足 6 位 |
| `NOT_FOUND` | 订单不存在或查询信息不匹配 | 三元组联合匹配失败 |
| `INTERNAL_ERROR` | 开放接口调用失败，请稍后重试 | 服务端异常兜底 |

> 每次成功通过 API Key 校验的调用都会写入 `ai_studio_audit_logs` 审计集合（`action: 'open_api_call'`，含 `apiAction` 与可选 `orderId`、`db.serverDate()` 时间戳），便于事后审计与异常排查。

### 2.3 action = catalog（套餐与主题目录）

**入参**：`payload` 无需传值（`{}` 即可）。

**返回**：

```json
{
  "success": true,
  "products": [ ... ],
  "themes": [ ... ],
  "styles": [ ... ],
  "categories": [ ... ]
}
```

| 数组 | 字段 |
|------|------|
| `products` | `productId`、`name`、`price`、`deliveryCount`、`productionLine`（auto / semi_auto / manual_ai）、`description`；`portrait_suite_69` 套餐额外含 `productType: "portrait"`（其 price 为单主题基础价，多主题实付以 createOrder 服务端阶梯计价为准） |
| `themes` | 写真套图可选主题（与小程序一致）：`themeId`（guofeng / sports / casual / travel / family）、`name`、`desc`、`sceneHint` |
| `styles` | standard 套餐（证件照/简历照）风格：`styleId`（ID-01 / ID-02 / ID-03 / BZ-01）、`category`、`name`、`productionLine` |
| `categories` | 品类分组（id_photo / business / portrait，兼容旧接入方） |

当前套餐目录（服务端常量，与小程序端 `utils/ai-studio-config.js` 同构维护）：

| productId | name | price | deliveryCount | 说明 |
|-----------|------|-------|---------------|------|
| `id_photo_9_9` | 3.9 证件照体验版 | 3.9 | 1 | 自动产线，1 张高清电子版 |
| `resume_photo_29_9` | 29.9 简历形象照 | 29.9 | 3 | 半自动产线，商务风格 |
| `portrait_suite_69` | 69.9 人像写真套系 | 69.9 | 5 | `productType: portrait`，人工精修交付 |

### 2.4 action = queryOrder（三元组查询订单）

**入参** `payload`：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `orderId` | string | 是 | 订单号，最长 80 字符 |
| `contactPhone` | string | 是 | 下单手机号，需为合法 11 位大陆手机号 |
| `queryPassword` | string | 是 | 查询密码，至少 6 位，最长 32 字符 |

**返回**（成功）：

```json
{
  "success": true,
  "order": {
    "orderId": "AIStudio-xxxxxx-xxxxxx",
    "productId": "...",
    "order_status": "delivered",
    "payment_status": "paid",
    "...": "订单其余字段（已剥离 queryPasswordHash）"
  },
  "files": [
    {
      "fileId": "ai_studio_files 文档 ID",
      "fileType": "...",
      "fileID": "云存储 fileID",
      "fileName": "...",
      "size": 1024,
      "status": "...",
      "createdAt": "..."
    }
  ]
}
```

**安全说明**：服务端以 `orderId + contactPhone + SHA256(queryPassword)` 三元组联合匹配订单，返回前剥离 `queryPasswordHash`，文件仅输出公开字段（`fileId/fileType/fileID/fileName/size/status/createdAt`）。

### 2.5 action = paymentQR（收款码）

**入参**：`payload` 无需传值。

**返回**：

```json
{ "success": true, "config": { "fileID": "cloud://...", "note": "收款说明" } }
```

- `config` 为收款码配置（云存储 fileID + 备注），由商家后台 `adminSetAIStudioPaymentQR` 写入 `ai_studio_payment_config`（`configId: 'default'`）。
- 尚未配置时返回 `{ "success": true, "config": null }`。

### 2.6 action = runtimeConfig（公开运行配置）

**入参**：`payload` 无需传值。

**返回**：

```json
{
  "success": true,
  "config": {
    "modelSettings": [ ... ],
    "promptTemplates": [ ... ],
    "routes": [ ... ]
  }
}
```

- 读取 `ai_studio_model_settings` / `ai_studio_prompt_templates` / `ai_studio_routes` 三个集合中 `enabled: true` 的条目。
- 输出已做脱敏（剥离 `_id`、`_openid`、`apiKey`、`secret`、`token`、`headers`、`content`）。
- 集合为空或读取异常时回退到内置默认配置（返回附 `message: "使用默认影楼运行配置"`）。

## 三、部署步骤（商家 / 管理员操作）

1. **上传云函数**：在微信开发者工具中右键 `cloudfunctions/photomuseOpenApi` →「上传并部署：云端安装依赖」（函数纯依赖 `wx-server-sdk`，无其他外部依赖）。
2. **配置环境变量**：云开发控制台 → 云函数 → `photomuseOpenApi` → 函数配置 → 环境变量，新增：
   - 键：`AI_STUDIO_OPEN_API_KEYS`
   - 值：逗号分隔的 API Key 白名单，例如 `pm_open_a1b2c3d4e5,pm_open_f6g7h8i9j0`
   - 建议用随机长字符串生成（如 `openssl rand -hex 16`），一个接入方一个 key，便于吊销与审计。
   - **未配置该变量时，所有调用一律返回 FORBIDDEN。**
3. **开启 HTTP 访问（云接入）**：控制台 → 云函数 → `photomuseOpenApi` → 开启「云接入 / HTTP 访问服务」，路径建议 `/openapi`，得到形如 `https://<环境ID>.service.tcloudbase.com/openapi` 的地址。鉴权方式选择接口自行校验（本函数以 API Key 鉴权）。
4. **建议配置白名单**：在云接入 / 网关层为 `/openapi` 路径配置 referer 白名单（网站接入方）或来源 IP 白名单（后端接入方），作为 API Key 之外的第二道防线。

## 四、安全注意事项

1. **API Key 保管**：API Key 等同于接入密码，只放在**服务端 / 后端**环境变量中；**切勿**写死在网站前端代码、小程序源码或公开仓库里（前端会被反编译 / 抓包拿到）。网站类接入请通过自家后端中转调用。
2. **queryOrder 三元组即权限边界**：订单查询不依赖用户登录态，`orderId + 手机号 + 查询密码` 就是该订单的全部凭证。请引导用户妥善保管查询密码；接入方前端不得缓存明文密码。
3. **务必走 HTTPS**：云接入地址本身是 HTTPS，请勿通过任何 HTTP 明文代理转发信封（内含 API Key 与查询密码）。
4. **速率控制**：一期不做按 OPENID / 来源的复杂限速，由云函数并发与调用频率限额兜底；所有通过鉴权的调用均写入 `ai_studio_audit_logs`（含服务端时间戳），异常高频调用可事后审计定位。
5. **最小暴露原则**：接入方只需展示目录与查询订单时，仅使用只读 action（`catalog` / `queryOrder` / `paymentQR` / `runtimeConfig` / `businessConfig` / `samples` / `merchandise`）；写操作（`createOrder` / `registerPhoto` / `submitOrder` / `getOrder` / `selectCells` / `analyzePhoto` / `selectMerch`）以 webToken / 三元组为权限边界，管理类函数（审核/交付/导出制作稿等）不通过本网关开放。

## 五、示例代码

### 5.1 Web SDK 匿名登录 + callFunction 调 queryOrder（网站）

```html
<script src="https://imgcache.qq.com/qcloud/cloudbase-js-sdk/1.7.0/cloudbase.full.js"></script>
<script>
  (async () => {
    const app = cloudbase.init({ env: '浅焦映像云开发环境 ID' });
    const auth = app.auth({ persistence: 'local' });
    await auth.signInAnonymously(); // 匿名登录

    const res = await app.callFunction({
      name: 'photomuseOpenApi',
      data: {
        apiKey: 'pm_open_a1b2c3d4e5', // 建议由自家后端中转持有，勿直接放前端
        action: 'queryOrder',
        payload: {
          orderId: 'AIStudio-1723766400000-ab12cd',
          contactPhone: '13800138000',
          queryPassword: 'abc123'
        }
      }
    });

    const result = res.result;
    if (result.success) {
      console.log('订单状态:', result.order.order_status);
      console.log('交付文件:', result.files);
    } else {
      console.error('查询失败:', result.code, result.message);
    }
  })();
</script>
```

### 5.2 curl 直接调用（任意后端 / HTTP）

```bash
curl -X POST "https://<环境ID>.service.tcloudbase.com/openapi" \
  -H "Content-Type: application/json" \
  -d '{
    "apiKey": "pm_open_a1b2c3d4e5",
    "action": "queryOrder",
    "payload": {
      "orderId": "AIStudio-1723766400000-ab12cd",
      "contactPhone": "13800138000",
      "queryPassword": "abc123"
    }
  }'
```

其他 action 只需替换 `action` 与 `payload`，例如获取目录：

```bash
curl -X POST "https://<环境ID>.service.tcloudbase.com/openapi" \
  -H "Content-Type: application/json" \
  -d '{"apiKey": "pm_open_a1b2c3d4e5", "action": "catalog", "payload": {}}'
```
