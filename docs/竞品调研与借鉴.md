# 浅焦映像 · 竞品调研与借鉴（2026-08-22）

> 调研范围：GitHub 同类开源项目（AI 证件照 / AI 写真 / 影楼小程序）。结论先行：**同类项目都只做了"生成"这一环，我们的完整商业闭环（计价/支付/选片/周边/印刷稿/开放 API）是独有优势；但我们缺的"全自动生成"恰好有 Apache-2.0 许可的开源引擎可以直接集成。**

## 一、核心对标项目

### 1. HivisionIDPhotos（16.9k★，Apache-2.0）⭐ 最高借鉴价值
https://github.com/Zeyi-Lin/HivisionIDPhotos

轻量级 AI 证件照引擎：抠图（MODNet 系，**纯 CPU 0.2 秒/张、内存 410MB**）→ 换底色 → 尺寸规格生成 → **六寸排版照**（含裁剪线）。提供 FastAPI API 服务 + Docker 一键部署；API 参数含底色 HEX / 美颜 / **dpi** / 人脸对齐 / base64 输入。

**可直接借鉴（按优先级）：**
1. **自部署为证件照生图引擎**：Docker 一条命令起 API，`generateAIStudioImage` 增加 `provider: 'hivision'` 分支调它的接口（idphoto / add_background / generate_layout_photos）——**¥3.9 证件照从"人工修图"升级为全自动秒级出图**，边际成本趋近于零，最引流的产品率先自动化
2. **中国证件照规格库**：其 `size_list_CN.csv`（尺寸名+高+宽 px）与 `color_list_CN.csv`（标准底色 HEX，如蓝 #4f83ce）抄录进 `utils/ai-studio-config.js`——我们现在只有"白底/蓝底"文字选项，补上"一寸/二寸/小二寸/签证/考试报名"真实规格
3. **排版照打印品类**：六寸/五寸/A4/3R/4R 排版+裁剪线，正好给周边货架加一个"排版照冲印"SKU，与我们的 300DPI 制作稿管线天然衔接
4. **API 细节**：美颜参数可暴露为用户选项（轻修/自然/原图）；水印字体机制；自定义尺寸支持毫米单位（与我们 printSpec 同思路）
5. **许可证**：Apache-2.0，**可商用集成**，注意保留其版权声明

### 2. FaceChain / FaceChain-FACT（阿里 ModelScope，近万★）
https://github.com/modelscope/facechain

"开源版妙鸭相机"：LoRA 训练式写真（3+ 张照片训练专属人脸 LoRA 再生成）；**FACT 版 10 秒免训练、单图生成**、身份保持。有 SD-WebUI 插件。

**借鉴**：这是写真套图线"全自动批量出 15 分镜"的技术升级路线。两条落地方式：① 有 GPU 服务器自部署（需 16GB 显存级）；② 等托管 API（ModelScope/硅基流动）成熟后接入我们已有的 OpenAI 兼容生图配置体系。列入 Roadmap，现阶段维持"管理员一键触发生图 API + 人工兜底"。

### 3. PhotoMaker（腾讯，免训练）
输入 1-N 张人脸 + 文本描述秒出写真/漫画风——与 FaceChain-FACT 同路线的备选引擎。

## 二、差距与机会总结

| 维度 | 同类开源 | 我们 | 动作 |
|---|---|---|---|
| 自动生成 | ✅ 强（引擎级） | ❌ 半自动（调外部生图 API+人工兜底） | **集成 HivisionIDPhotos 自部署引擎（证件照线先自动化）** |
| 规格专业度 | ✅ 完整规格库/标准色值 | ⚠️ 仅文字选项 | 抄录规格库 + 真实底色 HEX |
| 排版打印 | ✅ 六寸排版+裁剪线 | ✅ 300DPI 制作稿（无排版） | 排版照加进周边 SKU |
| 商业闭环 | ❌ 无（不收费/无订单） | ✅ 计价/收款/选片/周边/物流/审计 | 保持领先 |
| 多端 | 部分 | ✅ 小程序+网站+开放 API | 保持领先 |
| 写真身份一致性 | ✅ FaceChain/PhotoMaker | ⚠️ 提示词约束（依赖所配生图模型能力） | Roadmap：接入 FACT 类引擎 |
