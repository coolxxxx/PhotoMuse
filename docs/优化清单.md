## P1（可靠性 / 资损 / 性能）

- **契约大面积漂移**：后端从不返回 files 数组、fileType 名不符、定价键名不符、showcase 只认 cloud:// 而服务端给 https URL → 照片/成片/定价展示实际失效。证据：photomuse-web/order.html:106 vs server.js:293；pages/aiStudio/showcase/showcase.js:303。修法：以一份 schema 为准做交叉校验，扩展 tests/static/check-contracts.js 覆盖这些字段。
- **状态机无守卫 + 自动出图无幂等**：selectMerch 可把 completed 拉回制作态、每次 pass 都 kick 可重复烧钱生图、SMTP 抛错订单永久卡 generating。证据：server.js:325-334、server.js:844-847、lib/pipeline.js:44-46。修法：UPDATE ... WHERE order_status IN (...) 白名单迁移 + run() 抢锁。
- **周边计价可伪造**：价格/数量由客户端上送直接入库。证据：server.js:329-331。修法：只收 merchId+qty，服务端按 merchandise 表核价。
- **查询页凭证通道断裂**：三元组查到订单后，选片/周边仍被 requireOrder（只认 webToken）拒绝。证据：photomuse-web/js/order-view.js:541 vs server.js:255-260。修法：三元组可换短时 webToken。
- **供应链**：31 个云函数 wx-server-sdk 全为 "latest" 且 0 个 package-lock；运行时 Nodejs16.13 已 EOL；scripts/gen-landscape.js:12 与 scripts/gen-theme-samples-v2.js:15 硬编码 API Key 兜底字面量（值略）。
- **测试链盲区**：npm test 四段不含后端 38 用例。证据：package.json:7 vs package.json:14。修法：把 node --test tests/server.test.mjs 并入 npm test。
- **性能**：上传走 memoryStorage（单请求 12MB×6 全进内存）+ writeFileSync 同步写盘阻塞事件循环。证据：server.js:60-63、server.js:751-781。
- **小程序体验**：分页缺失（pages/aiStudio/index.js:516 固定 page:0）、onLoad+onShow 双份请求、token 过期无自愈（utils/photomuse-api.js:72-77）、admin 一次 setData 20 单全量数据 + 图片无 lazy-load。
